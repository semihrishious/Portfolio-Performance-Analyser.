# Portfolio Performance Analyzer

This project is a Python based portfolio analytics tool that downloads historical market data, calculates key performance and risk metrics, generates visualizations, and automatically creates an Excel report summarizing portfolio performance.

The project demonstrates practical applications of quantitative finance concepts using Python.

## Features
- Downloads historical stock prices
- Calculate daily returns
- Calculate cumulative returns
- Calculate portfolio return
- Calculate portfolio risk (volatility)
- Calculate CAGR
- Calculate Sharpe Ratio
- Calculate Maximum Drawdown
- Calculate Portfolio Beta
- Calculate Portfolio Alpha
- Compare portfolio performance with benchmark
- Generate professional charts
- Automatically generates a Excel report which summarises above

## Finance Concepts Used/Covered
- Portfolio Return
- Annualized Volatility
- Compounded Annual Growth Rate (CAGR)
- Sharpe Ratio
- Maximum Drawdown
- Capital Asset Pricing Model (CAPM)
- Portfolio Beta
- Portfolio Alpha
- Portfolio Diversification

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
- OpenPyXL

## How to Run
1. Clone the repository.
2. Install the required libraries.
3. Open `main.py`.
4. Update the portfolio tickers(Comapnies) and weights as applicable.
5. Run the program.
